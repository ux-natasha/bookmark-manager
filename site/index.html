Keep the parts of the internet you'd like to see again

Folia is a bookmark manager you'll actually look at. Every page, picture, quote and note is saved as you saw it, so you find things by how they looked.

Start your library in two minutes.

Folia isn't in the web stores yet, so you load it yourself. It works in Chrome, Edge and other Chromium browsers.

Get the code on GitHub

  1. Build itRun npm install, then npm run build. This makes a dist folder.
  2. Open extensionsGo to chrome://extensions or edge://extensions and turn on Developer mode.
  3. Load itClick Load unpacked and choose the dist folder.
  4. Pin itPin Folia to the toolbar, then press Alt+Shift+S on any page worth keeping.
