Features

Bookmarks you'll want to look at.

Folia turns a list of forgotten links into a library you can browse.

i.

Save in one click

Press Alt+Shift+S, or right-click a link, picture or selected text to keep it without leaving the page.

ii.

Visual by default

Every bookmark gets a preview, either a screenshot or the site's own image.

iii.

Links, quotes, pictures, notes

Everything lives together in one library, filterable by kind and searchable by text.

iv.

Find it by colour

Pick a colour and see everything that looked like it.

v.

Links from posts

Paste a post from X, Bluesky, Mastodon, Reddit or Hacker News and save the links it mentions.

vi.

Refresh my memory

Bookmarks you haven't opened fade, and old favourites come back to find you.

Colour search

Remember it was green?

You don't always remember a name, but you often remember a feeling. Folia lets you search the way memory works.

  • Brand-colour cards for pages with no preview
  • Platform detection for Substack, YouTube, GitHub and more
  • Dead link checks run quietly in the background

Your library stays yours.

Everything is stored locally in your browser. Back up to a JSON file whenever you like, and bring in your Edge favorites in a click.
