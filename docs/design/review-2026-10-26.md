# Design review of the built library (26 Oct 2026)

This review compares the code in `src/` against `library-interactions.md`, `theme-contact-sheet.md`, `theme-colour-field.md` and `theme-covers.md`, and against four screenshots (Default, Contact sheet, Covers, Colour field dark).

Findings are ranked by priority:

- **P0:** it breaks the design or is plainly wrong on screen.
- **P1:** it visibly misses the spec.
- **P2:** polish, accessibility or robustness.

Each finding gives the file and line, then what is wrong and the fix.

---

## 0. Before anything: the screenshots are from an older build

All four screenshots show a lone **"Refresh my memory"** button and no Look ahead panel. The current source cannot render that:

- `Library.tsx:382–390` builds a Look ahead panel for every theme, and it is placed at `:554` (Default) and `:569` (the other three).
- `copy.ts:127`, `:152` and `:189` give the button a different label in each theme: "Reprint the three most faded", "Bring back three" and "Take three down". "Refresh my memory" (`copy.ts:87`) is the Default label only.

**Action:**

1. Run `npm run build`.
2. Reload the extension in `edge://extensions`.
3. Take the four screenshots again.

Everything below was checked against the **source**. Where a screenshot problem is still in the source, the finding says so.

## P0: plainly wrong on screen

### P0.1 Default cards were never rebuilt (phase 2 of the build plan)

The spec (6.10) says each card is an `<article>` with no border or background of its own, with per-kind anatomy.

- **`library.css:412`**: the comment still reads `/* Cards (restyled in phase 2) */`. `.card` (`:413–420`) has `background: var(--surface)`, a 1px border and `overflow: hidden`. That is why the Default screenshot shows boxed white cards.
  - Fix: remove the border and background, and remove `overflow: hidden`, which also clips the halo and the lift.
  - Round only the media, using `--radius-media` with an inset 1px `--border` ring.
- **`BookmarkCard.tsx:46`**: the halo is only rendered when there is a `glow` colour, which only Colour field provides.
  - Default needs a halo too: the image's dominant colour or the fallback colour, blurred 24px, inset 12% 6% -8%.
  - Fix: render `.card-halo` for every link and picture card, with the colour from `b.color ?? b.themeColor ?? fallbackColor(b)`.
- **`BookmarkCard.tsx:64–66` and `library.css:575`**: Edit is always visible.
  - Fix: add `.card-meta .link { opacity: 0; transition: opacity 150ms }`.
  - Show it on `.card:hover` and `.card:focus-within`.
  - Under `@media (hover: none)`, set it to `opacity: .7`.
- **`library.css:735–746`**: the quote card uses `border-left: 3px solid var(--accent)`. The spec has a hanging quote mark instead.
  - Fix: remove the left border.
  - Add `.card-kind-quote .card-body::before { content: '“'; position: absolute; top: -10px; left: -4px; font: 70px/1 var(--font-serif); color: var(--accent) }`, with `padding-top: 30px` on the quote.
  - The source title (`BookmarkCard.tsx:205`) should be serif italic 15px muted, not `font-weight: 600`.
- **`BookmarkCard.tsx:212–227` (NoteContent)**: there is no note paper and no "your note · Oct 22" top line.
  - Fix: in CSS, give `.card-kind-note .card-link` `background: var(--note-paper)`, `border-radius: var(--radius-note)`, a 1px `--border` ring and `padding: 18px 18px 16px`.
  - Add a mono 11px muted top line.
  - The body should use the note-body style (serif italic), not `.small`.
- **`BookmarkCard.tsx:189` and `:192`**: the picture card prints a `Picture` chip, and then the title again (which shows as "Image" for untitled pictures).
  - The spec says: "Title isn't repeated, because the meta line names the source."
  - Fix: remove both. Move the source into the age text: "picture from slowtravel.blog · …".
- **`BookmarkCard.tsx:154–158` and `library.css:497–507`**: the dead link shows a red pill at bottom-left.
  - The spec asks for a stamp: "MAY BE DEAD", top-right 14px/12px, rotated 4°, mono 10px 500, `--danger` text and a 1.5px border on `--surface`.
  - The media should be `grayscale(1) opacity(.65)`. Today it is only `opacity: .6` (`:509`).
- **`BookmarkCard.tsx:147–150`**: the no-preview fallback is a centred icon and name.
  - The spec wants the site colour at 1.91:1, with the site name bottom-left in mono 11px and the **title over it** in serif 19px 500. The ink must be whichever of white or `#15171A` has more contrast.
  - Fix: reuse `coverColors()` from `lib/covers.ts` for the ink, so it is the same rule as Covers.

### P0.2 Age text ignores the spec in every theme, and ignores Look ahead

The same wrong logic is written three times:

- `BookmarkCard.tsx:57`: `formatDate(createdAt)`
- `Sheet.tsx:244–249`: `"opened " + formatDate(lastOpenedAt)`
- `Rack.tsx:154–159`: the same as Sheet

None of them follow the table in 6.10 ("opened this week", "untouched 14 mo.", "never opened, 14 mo."). None of them read `now` from `AgeContext`, so the text doesn't move when Look ahead steps forward. That is half the point of Look ahead. The source prefix ("quote · …", "your note · …") is also missing.

**Fix:**

1. Add one function to `lib/age.ts`:

   ```ts
   export function ageLabel(b: Bookmark, now: number): { text: string; danger?: boolean } {
     if (isDeadLink(b)) return { text: b.lastCheckedAt ? `stopped answering ${formatDate(b.lastCheckedAt)}` : 'stopped answering', danger: true };
     const months = monthsUntouched(b, now);
     const days = months * 30.44;
     const note = kindOf(b) === 'note';
     if (days < 7) return { text: note ? 'written this week' : 'opened this week' };
     if (months < 1) return { text: note ? 'written this month' : 'opened this month' };
     const mo = `${Math.round(months)} mo.`;
     return { text: b.openCount === 0 && !note ? `never opened, ${mo}` : `untouched ${mo}` };
   }
   export function sourcePrefix(b: Bookmark): string { /* host · / picture from host · / quote · / your note · */ }
   ```

2. Call it from all three layouts, with `age.now` (add `now` to `ItemAge` in `ageContext.ts:292`).
3. Keep the theme-specific "revived" text as it is.
4. Add a few cases to `age.test.ts`: a week, a month, never opened, and Look ahead +12.

### P0.3 Covers: mastheads break mid-word

The screenshot shows "COMPONEN TS" and "HUGEICONS. COM".

- **`covers.css:560`**: `overflow-wrap: anywhere` is applied to `.cover-masthead`, along with the titles. At `12.6cqi` uppercase (`:590`), any word longer than about 10 characters breaks wherever it runs out of room.
  - Fix: take `.cover-masthead` out of that shared rule. Give it `overflow-wrap: normal; hyphens: manual; white-space: normal`, and size it to its longest word:

    ```css
    .cover-masthead { font-size: min(12.6cqi, calc(128cqi / var(--mast-len, 10))); }
    ```

  - Set `--mast-len` in `Cover.tsx:313` from the longest word in `spec.masthead` (cover inner width ≈ 84cqi, display caps ≈ 0.65em per character).
- **`covers.ts:136`**: the masthead falls back to the bare hostname.
  - Fix: add `mastheadFor(host)`. It strips `www.` and the TLD and title-cases the rest: `hugeicons.com` → "Hugeicons", `fieldnotes.substack.com` → "Fieldnotes".
  - The full host stays in the kicker (`:137`), so nothing is lost.

### P0.4 Covers: aged covers lose their text contrast

**`covers.css:1531–1540`**: the "sun" wash is near-white (`rgb(255 248 230 / .9)` → transparent), at `opacity: t × .6`, layered **over** the text (`z-index: 2`).

- An imported library is almost entirely at t = 1 (see P1.1). Every light-ink cover (purple, green, navy) gets a white veil at the top, exactly where the masthead sits. That is the low-contrast text in the screenshot.
- `coverColors()` in `covers.ts:199` passes 4.5:1, but only for the un-aged cover.

**Fix:**

- On covers whose `ink` is `LIGHT_INK`, age them by **yellowing** rather than whitening. Do this with `mix-blend-mode: multiply` and a warm tint such as `rgb(236 214 170)`, so the background darkens and warms and contrast with light ink goes **up**.
- Keep the current wash only for dark-ink covers.
- Expose the ink as `data-ink="light|dark"` on `.cover` in `Cover.tsx:315`, and switch the `::before` rule on it.

### P0.5 Covers: the fallback colours are garish

**`covers.ts:143–145`**: `itemColor()` uses `fallbackColor(b)`, the saturated hashed hue meant for Default's no-preview tiles. Many sites have no `themeColor`, so the rack becomes a candy shelf.

**Fix:**

1. Prefer `b.color` (the colour read by `colorPass`, already in the DB for Colour field), then `themeColor`.
2. Failing both, hash the host into a **curated cover palette**: the 8 muted cover colours from the N boards (bottle green `#24453B`, oxblood, ink navy, ochre, and so on), not a free hue.
3. Run every result through `coverColors()` as now.

### P0.6 Contact sheet: long quotes and post titles blow up the rows

**`contact.css:673–682`**: `.sheet-quote` is `clamp(36px, 3.8vw, 52px)`, with no line limit. A 400-character quote fills the screen.

**`contact.css:660–664`**: `.sheet-title` is 31px with no clamp. Social posts arrive with the post body as their `title` (PST items), so they hit this too.

This is a gap in my spec. I gave the size but no limit.

**Fix:**

- Quote: `display: -webkit-box; -webkit-line-clamp: 6; -webkit-box-orient: vertical; overflow: hidden`. Step the size down by length in `Sheet.tsx:148`:
  - ≤ 90 characters: as now
  - ≤ 200 characters: `data-long` → 28px
  - longer: `data-very-long` → 22px with a clamp of 8
- Title: clamp to 3 lines. For `codeKind === 'PST'`, use 20px/1.3 with a clamp of 5. A post is read like a quote, not a headline.
- The full text stays in the accessible name and opens on click, so nothing is hidden for good.

**`contact.css:421`**: `grid-auto-rows: minmax(300px, auto)` makes every cell in a row as tall as its tallest neighbour. This is why the note cells stretch.

- Equal rows are right for a contact sheet. Once quotes are clamped, the rows come back to a sane height.
- Also anchor the note text to the top and let the meta row sit at the bottom: `.sheet-note { flex: 1 }` already does this, so leave it.

### P0.7 Colour field: the room is clipped flat at the bottom edge

I rebuilt the room from `field.css` in Chromium.

- Inside the viewport it renders correctly: soft lights.
- But lights 4 and 5 (`field.css:179–191`) sit at `bottom: -260px` and `-240px` with a 100px blur, inside a container with `overflow: hidden` (`:145`). Their blur is cut off along the viewport's bottom edge, giving a hard horizontal edge.
- On a scrolling page that edge is the bottom of the window. In a full-page screenshot it becomes the "hard band" you saw.

**Fix:**

- Let the blur run off-screen before it is clipped: `.field-room { inset: -240px; }`, keeping `overflow: hidden`.
- Move the lights inwards by the same 240px, so the composition is unchanged.
- Separately, `field.css:149–155` and `:940–947` both define `.field-light` (`opacity`, `filter`, `transition`). Merge them into one rule; the second silently overrides the first.

## P1: visibly misses the spec

### P1.1 An imported library is entirely "faded" on day one (decision needed)

- **`age.ts:341–344`**: `lastTouched` is `max(createdAt, lastOpenedAt, dustedAt)`.
- Imported favourites keep Edge's `date_added` as `createdAt`, so anything you bookmarked more than 12 months ago arrives at t ≥ 0.5, and anything over 24 months at t = 1.
- The Covers dateline reads "VOL. 8" for the same reason (`Library.tsx:907–914`).
- With everything already aged, patina carries no information, and "Refresh my memory" picks from the whole library.

**Recommendation:** in the importer, set `dustedAt = importTime` on every imported record. Imports then start fresh and age from the day they arrived, without inventing an "opened" event, and `openCount` stays truthful. This needs no schema change.

If you'd rather old favourites arrive already yellowed, that's a valid choice. Then patina needs a scale per library, which I wouldn't do.

**Volume:**

- Count from the first item that **wasn't** imported: `source !== 'import'`.
- Or drop "VOL." entirely, as `theme-covers.md` decision 4 allows.

### P1.2 The quote source tint doesn't age (Colour field)

**`field.css:491–494`**: the quote's tint is `color-mix(--glow 42%, transparent)`, with no `--t` term. A faded quote keeps its full colour while every other card drains.

**Fix:** use `calc(42% * (1 - var(--t, 0)))` as the mix amount.

### P1.3 Dark swatches disappear (Colour field)

**`field.css:305–316`**: a swatch has a 2px `var(--bg)` border (`#0E1116`) and a 1px ring at 16% white. A black or near-black swatch on the dark room is effectively invisible.

**Fix:**

- Raise the ring to `rgba(255,255,255,.32)`.
- Add `inset 0 0 0 1px rgba(255,255,255,.18)`.
- Or compute luminance in `ColourSearch.tsx` and set `data-dark` on swatches below 0.05, giving those the inner highlight.

### P1.4 The filed-under line sits in the wrong place on Default cards

**`BookmarkCard.tsx:54`**: the filed-under line is rendered in the footer next to the meta row. The spec puts it "below the title, or below the quote or note text".

**Fix:** move it inside `card-body`, after the title, quote or note.

### P1.5 Contact sheet: quotes have no source

**`Sheet.tsx:148`**: the quote has no source line. The corner label gives the hostname (`:235–236`), but the page title does not appear anywhere.

**Fix:** the spec's corner label is fine. Also add the title to the cell's accessible name, so screen readers hear where it came from.

### P1.6 Contact sheet: the meta row truncates the age text

**`contact.css:741–748`**: `.sheet-age` is `flex: 1; white-space: nowrap; text-overflow: ellipsis` and shares a wrapping row with the tags. When tags are present, the age text loses.

**Fix:** put the tags on their own line. Use `.sheet-tags { flex-basis: 100% }`, so the age text always gets the full row next to Edit.

### P1.7 Default headline and Jot placeholder

- **`copy.ts:97`** and **`library.css:145`**: the headline wraps at about 1100px, because `.hero-side` (`library.css:102–107`, `flex: 1 1 360px`) takes room from it.
  - Fix: give `.hero-main` `flex: 1 1 560px`.
  - Or cap the headline at `clamp(46px, 5.6vw, 76px)` while Look ahead sits beside it.
- **`JotNote.tsx:37`**: "Jot a note, it lands with everything else" is longer than the field at 340px with the Save button, so it truncates.
  - Fix: use "Jot a note…", and move the rest into `title` or the help text.

## What's right and should stay

- One `now` through `AgeContext`, with `--t` handed to CSS (`ageContext.ts`). It's a clean seam, and every theme ages from it.
- `dustOff` and `undoDustOff` keep `openCount` truthful, and the snapshot Undo (`Library.tsx:307–348`) is well put together.
- The Look ahead parts are shared (`lookAheadParts.tsx`): keys, focus handling at the ends, one action button that keeps focus. These are good.
- The tag index starts collapsed. Picking closes it unless a modifier is held, and focus returns to the opener (`Library.tsx:283–298`). This matches the spec.
- `coverColors()` does a real WCAG check with darkening. Only the ageing layer (P0.4) defeats it.
- The Contact sheet codes are `aria-hidden`, with a hidden kind word first (`Sheet.tsx:98–102`), as specified.
